# Tanzania Lakes and Rivers Shapefile

GIS shapefile datasets for Tanzania hydrography.

## Included datasets

- `Tanzania_Rivers` — river features
- `Tanzania_Water_Bodies` — lakes and other water-body features

Each dataset includes the standard Shapefile component files (`.shp`, `.shx`, `.dbf`, `.prj`, and `.cpg`).

## Use in QGIS

Open the corresponding `.shp` file in QGIS using **Layer → Add Layer → Add Vector Layer**. Keep all component files with the same basename together in the same folder.
